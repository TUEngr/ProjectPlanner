    Using Project Planner

    • Durations are in working days (Mon–Fri, minus holidays from Settings). Type 5, 5d, or 2w. A duration of 0 makes a milestone ◆.
    • Predecessors: list the row numbers that must finish first, e.g. 2, 5. All links are finish-to-start.
    • Dates: start and finish are calculated. Typing a Start date pins the task there 📌; click the pin to release it. Typing a Finish date changes the duration.
    • ⚠ warnings mark problems such as a pinned task that starts before its predecessor finishes, or a circular dependency. Hover for details.
    • Summary tasks: select a task and click Indent to make it a subtask of the row above. Summary rows roll up dates and progress from their subtasks.
    • Critical path (red) is the chain of tasks with zero float: any slip in them delays the finish. Float is how many working days a task can slip without delaying the project.
    • Saving: plans save automatically in this browser. Use Save file / Open file for backups or to move plans between computers. Clearing browser data deletes local plans.
    • Printing: Print prints the Gantt chart at the current zoom; choose “Save as PDF” in the print dialog for a PDF. Use the Weeks or Months zoom for long projects.
